# مروان يوسف البلوشي

مدونة شخصية. جميع الملفات في مستوى واحد، بلا مجلدات.

| الملف | وظيفته |
|---|---|
| `index.html` | المدونة كاملة: التصميم والتصفّح والأبواب |
| `data.json` | ١٬٩٨٠ مدخلاً |
| `radud.html` | أرشيف الردود المخفيّ |
| `radud.json` | ٤٬٠٠١ ردّ |
| `404.html` | صفحة الخطأ |
| `robots.txt` | منع فهرسة الأرشيف المخفيّ |

## الوسائط

الصور تعمل الآن من مصدرها الأصلي. ولنقلها إلى مستودعك:
افتح `index.html` واضغط تعديل، وابحث في أول السطور البرمجية عن:

```
var MEDIA_BASE = "";
```

وضع بين علامتي التنصيص رابط مستودعك على Cloudflare R2، مثل:

```
var MEDIA_BASE = "https://pub-xxxx.r2.dev";
```

احفظ، وستتحوّل الوسائط كلها خلال دقيقتين، وتعمل المقاطع بالتشغيل المباشر.
