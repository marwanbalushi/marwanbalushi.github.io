# مروان يوسف البلوشي

مدونة شخصية ساكنة على GitHub Pages، نطاقها `marwanbalushi.com`.
كل شيء فيها يُقاد من `config.json` ويُحرَّر من لوحة `tahrir.html` — **لا حاجة إلى تحرير ملف بيدك.**

---

## البنية

### الملفات التي تُقاد منها المدونة

| الملف | وظيفته |
|---|---|
| `config.json` | الهوية والأبواب والألوان والخطوط والعرض وأزرار المشاركة ونطاق الوسائط |
| `data.json` | المداخل كلها — المصدر الوحيد للحقيقة |
| `data-recent.json` | أحدث ١٥٠ مدخلاً، تُحمَّل أولاً ليقرأ الزائر فوراً |
| `index.html` | هيكل المدونة وتنسيقها المدمج |
| `render.js` | محرّك العرض: الترويسة والأبواب والبحث والمداخل |
| `p/style.css` | تنسيق الصفحات المستقلّة — **يُولَّد من `config.json`** ولا يُحرَّر يدوياً |

### ما يُولَّد تلقائياً — لا تحرّره

| الملف | متى يُكتب |
|---|---|
| `p/*.html` | صفحة مستقلّة لكل مدخل منشور — عند الحفظ أو إعادة البناء |
| `about.html` | عند حفظ الإعدادات |
| `archive.html` | عند كل حفظ مدخل |
| `sitemap.xml` · `rss.xml` | مع كل حفظ |

### الإدارة

| الملف | وظيفته |
|---|---|
| `tahrir.html` + `panel.js` | لوحة التحرير — **لا تنشر رابطها** |
| `mift.json` | مفتاح GitHub مشفَّراً بجملة السرّ |
| `radud.html` + `radud.json` | أرشيف الردود المخفيّ |
| `sw.js` | عامل الخدمة: شبكة أولاً، والتخزين احتياط عند الانقطاع |
| `.nojekyll` | **لا تحذفه** — يمنع GitHub من العبث بالمجلدات |

## الوسائط

الصور والمقاطع في مستودع Cloudflare R2 اسمه `media`، ويُقدَّم من نطاق مخصّص:

```
https://media.marwanbalushi.com
```

وعنوانه مكتوب في `config.json` تحت `media.base`. **لا تكتبه في أي ملف آخر** — كل شيء يقرؤه من هناك.

والرفع من اللوحة يمرّ بوسيط Cloudflare Worker. رابطه ومفتاحه محفوظان داخل `mift.json` المشفَّر، **ولا يُكتبان هنا ولا في أي ملف عامّ.**

---

## الصفحات المستقلّة

لكل مدخل منشور صفحة قائمة بذاتها:

```
marwanbalushi.com/p/<رقم المدخل>.html
```

وهي التي تُشارَك، لأنها تحمل ترويسات المعاينة فيقرؤها واتساب وX وجوجل. **أما عناوين `#/` فلا تصلح للمشاركة** — ما بعد الشرطة لا يبلغ الخادم أصلاً.

والصفحة مكتفية بذاتها: نصّها ووسائطها مكتوبة فيها، لا يولّدها جافاسكربت.

## القواعد التي تعلّمتها بالتجربة

**١. بعد كل رفع من المتصفّح، اسحب إلى جهازك:**

```
cd %USERPROFILE%\Desktop\site && git pull --no-edit
```

وإلا رُفض أول `git push` بعده ووقع تعارض.

**٢. بعد التعديل الجماعي أو إضافة عدّة مداخل، اضغط «إعادة بناء الصفحات».**
فالتعديل الجماعي لا يمسّ الصفحات، وروابط «السابق والتالي» تتخلّف حتى تُبنى.

**٣. لا تحذف مفتاحاً حتى يعمل الذي بعده.**
الترتيب دائماً: أنشئ ← اربط ← ارفع `mift.json` ← جرّب الحفظ ← ثم احذف القديم.

**٤. المسوّدة تُخفي المدخل وتحذف صفحته.** فما تستره مستور فعلاً، لا في المدونة وحدها.

**٥. انسخ `data.json` إلى قرص خارجي شهرياً.**
كل ما في هذا المستودع يُعاد بناؤه في ساعة. وبياناتك لا تُعوَّض.
